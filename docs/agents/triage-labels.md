# Triage 状态

Skills 使用五个 canonical triage 状态。对本地 Markdown issue，在文件顶部附近的 `Status:` 行填写右侧字符串。

| Canonical 状态 | `Status:` 中的字符串 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由 agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提到某个 triage 状态时，使用表中对应的字符串；如需更改本仓库的状态词汇，编辑右侧一列。
